```
【非官方】自動定時查詢 813 國軍桃園總醫院新竹分院的看診進度，指定的診間一有異動、或快輪到你的號碼時立即通知。
```

**詳細說明**
```
【本擴充功能由個人開發，非國軍桃園總醫院新竹分院官方推出，未經該院授權或背書。】

看診等待時，不用一直開著看診進度網頁按重新整理。設定好要監看的診間，
叫號一有異動、或快輪到你的號碼時，Chrome 就會直接跳通知提醒你。

■ 主要功能

・可同時監看多個診間，每個診間的號碼與提醒條件都各自獨立
・填入自己的看診號碼後，可設定「剩幾號才提醒」（預設剩 3 號），
　不會每次查詢都被打擾
・工具列圖示直接顯示目前叫號，快輪到你時會變色，不用點開就看得到
・點開圖示可看到所有監看診間的即時狀態、你還差幾位、最後更新時間
・設定頁自動抓取當天的診間清單，依上午／下午／晚上分組，
　勾選就好，不必手動輸入科別或診間名稱
・支援淺色與深色模式

■ 通知時機（可各別開關）

・快輪到你了：剩 N 號時提醒，同一個號碼只提醒一次
・輪到你了 / 已經過號：各提醒一次
・進度異動：例如「看診進度 46 → 47」
・開始看診 / 看診結束：狀態改變時各一次

同一個診間使用固定的通知代號，新通知會取代舊的，不會在畫面上堆一整排。
快輪到你時也不會再重複發一則進度異動通知，避免同一件事跳兩次。

監看的診間全部看診結束後會自動停止密集查詢，改為每 30 分鐘確認一次，
隔天班表出來或診間重新開診時自動恢復，不會整天空轉。

■ 隱私

所有設定都只存在你自己的瀏覽器本機。不需註冊帳號、不蒐集任何個人資料、
無追蹤、無分析、無廣告。除了讀取醫院公開的看診進度資料之外，
不會連線到任何其他伺服器。

隱私權政策：https://github.com/goodspeed666/813_hospital_reminder/blob/main/PRIVACY.md

・看診進度以醫院現場公告為準，本工具僅供參考
```

## 5. 權限使用理由

**`storage`**
```
儲存使用者的設定：要監看哪些診間、使用者自行輸入的看診號碼、
提醒門檻與通知偏好。全部存放於 chrome.storage.local，不會離開使用者的裝置。
```

**`alarms`**
```
定時觸發看診進度查詢。Manifest V3 的背景 service worker 會被瀏覽器休眠，
setInterval 等計時器無法可靠運作，因此必須使用 chrome.alarms 排程。
```

**`notifications`**
```
本擴充功能的核心功能就是在看診進度變動或快輪到使用者時，
以桌面通知提醒。沒有這個權限就無法達成擴充功能的主要用途。
```

**`offscreen`**
```
播放提醒音效。Manifest V3 的背景 service worker 沒有 Audio / Web Audio API，
必須建立 offscreen document（理由為 AUDIO_PLAYBACK）才能發出提示音。
音效由 Web Audio 即時產生，未載入任何外部音檔。
```

**主機權限 `http://www.813.com.tw/*`**
```
讀取國軍桃園總醫院新竹分院公開的看診進度資料。這是該院「看診進度」
網頁本身所使用的公開資料來源，內容僅包含各診間的時段、科別、醫師、
診間名稱與目前叫號，不含任何病患個人資料。

該網站僅提供 http、未提供 https，因此無法只宣告 https 權限。
擴充功能不會存取該網域以外的任何網站。
```

**遠端程式碼**：選「否，我沒有使用遠端程式碼」
（所有程式碼都在封包內，沒有 eval、沒有載入外部 script）

## 8. 一個要有心理準備的風險

商店的「冒充與智慧財產權」政策規定：不得讓人誤以為你的產品經過該組織授權。
名稱裡帶有醫院全名，即使描述已註明非官方，仍有被審核判定冒用機構名義的可能，
醫院方也有權要求下架。

已經做的降低風險措施：摘要開頭就是「【非官方】」、詳細說明第一行是完整免責聲明、
設定頁標題旁有「非官方」標籤、隱私權政策裡也寫明未經該院授權或背書。

**如果被退件且理由與名稱有關**，把 `manifest.json` 的 `name` 改成下面這個、
版本號加一，重新上傳即可（其他內容都不用動）：
